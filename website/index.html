How it works

Two paths. Zero friction.

Keeto intercepts at the httpx transport layer — the HTTP client used by every major AI SDK. Drop two lines in and every call is captured. Or decorate your own pipeline stages for a stage-by-stage breakdown.

Auto-detect AI SDK calls
Keeto scans installed packages at startup and patches their HTTP transport. OpenAI, Anthropic, LangChain, Gemini — all captured automatically with zero code changes.
from keeto import monitor
monitor.start()

# keeto: loaded plugins → openai, anthropic

# Every call below is captured automatically
import openai
client = openai.OpenAI()
client.chat.completions.create(model="gpt-4o", ...)
Instrument your own pipeline
Building a RAG pipeline or multi-stage workflow? Use @trace to get a stage-by-stage latency breakdown with zero boilerplate.
from keeto import monitor, trace
monitor.start()

@trace("embedding")
def embed(text): ...

@trace("retrieval")
async def search(vec): ...

@trace("llm")
def generate(docs): ...

monitor.pipeline_breakdown()

Features

Everything you need.
Nothing you don't.

Keeto is the observability primitive that should have shipped with every AI SDK. Install once, forget about it, and get the data you didn't know you were missing.

Zero config
monitor.start() is the entire setup. Auto-detects OpenAI, Anthropic, LangChain, and more from installed packages.
Cost tracking
Every span captures input tokens, output tokens, cached tokens, and USD cost from a built-in pricing table.
@trace decorator
Wrap any sync or async function as a named span. Stage names like "embedding" and "llm" are auto-mapped to the right span kind.
Dashboards
Rich table in terminal, interactive Textual TUI, or a browser dashboard with live updates via Server-Sent Events.
PII scrubbing
scrub_pii=True redacts emails, SSNs, phone numbers, and credit card numbers before anything touches storage.
Budget alerts
Set daily or session cost and token budgets. Keeto fires a warning before surprise bills arrive, with optional webhook callbacks.
Export everywhere
JSON, CSV, OpenTelemetry OTLP, LangSmith, MLflow, Prometheus — all supported. Filter by time range.
Recommendations
Rule-based analysis flags oversized prompts, repeated identical calls, model switch candidates, and cache opportunities.
Replay
trace.replay() re-sends the exact captured request back to the provider — useful for debugging and regression testing.
Integrations

Works with every stack.

Keeto patches the httpx transport used by every major AI SDK. If your stack isn't listed, the @trace decorator covers anything else.

Install

Start in 30 seconds.

Requires Python 3.11+. Core has no heavy dependencies.

$ pip install keeto
$ uv add keeto
$ pip install "keeto[sqlite,tui,web]"
